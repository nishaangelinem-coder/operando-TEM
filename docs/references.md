## Note on citation practice

This project is a methodology and simulation study. The references above are used to
establish (i) what is experimentally demonstrated today, and (ii) the numerical values
of instrument and transport parameters adopted in the digital twin. No reference is
cited as support for any *result* produced by the simulator; simulated results are
attributed only to the simulator, as stated in the manuscript's integrity declaration.
